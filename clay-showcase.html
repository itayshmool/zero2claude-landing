Background

What is Clay?

Clay is an interactive visual micro-app builder. You describe what you want in natural language — "a particle system that feels like digital smoke" or "falling terminal commands with mouse repulsion" — and Clay generates a working, self-contained HTML canvas with live controls, mouse interactivity, and export options.

The Work

3 prompts. 3 hero effects.

Each concept was generated from a single prompt to Clay, then adapted for the landing page — theme-aware, performance-optimized, and accessible. Here they are.

Concept 01

Terminal Rain

Matrix-style falling terminal commands — cd, git commit, claude — color-coded by type. Mouse repulsion pushes characters aside. Perlin noise wind drifts the columns. Currently live on the main landing page.

Prompt sent to Clay
An interactive Matrix-style code rain visualization, but instead of random characters, the falling columns are real terminal commands from the zero2claude.dev curriculum — cd, ls, git commit, echo, curl, node, claude — falling at different speeds with a Perlin-noise wind effect. Mouse position creates a repulsion field that pushes characters away, like you're parting a curtain of code. Colors: orange (#FF6B35) for Claude-related commands, green (#22C55E) for basic terminal commands, muted gray for everything else. A blinking cursor follows the mouse. Controls: fall speed, wind turbulence, density, character size, color mode (monochrome green / branded / rainbow). On click, a "shockwave" ripples outward from the cursor. Background: deep navy (#09090B). Monospace font only.

Concept 02

Command Constellation

Terminal commands float like stars. Mouse proximity triggers glowing orange constellation lines between nearby commands. Commands are vertically layered by curriculum level — ls at the bottom, claude at the top. A literal map of the learning journey.

Prompt sent to Clay
A particle system where each particle is a terminal command from the curriculum (ls, cd, git push, claude, curl, npm start, etc.) rendered in monospace. Particles float gently in space like stars. When the mouse hovers near a cluster, they connect with glowing orange (#FF6B35) lines forming a "constellation" — visually showing how commands relate to each other. Clicking a command spawns a brief tooltip showing which level it's taught in ("Level 4: Your Code Has a History"). Commands from early levels drift at the bottom, advanced commands float higher — a literal visual of the learning journey. Controls: particle count, connection distance, gravity (pulls commands into level layers vs free float), glow intensity, background darkness. Monospace font, dark background (#09090B).

Concept 03

Cursor Journey

A blinking terminal cursor traces a noise-driven path upward through all 14 curriculum levels, leaving a color-graded trail — green to blue to orange. Level milestones fade in along the path. Mouse warps the flow field. The most narrative of the three.

Prompt sent to Clay
A generative path visualization: a single blinking terminal cursor (_) starts at the bottom-left and traces a flowing Perlin-noise path upward across the canvas, leaving a glowing trail. At intervals along the path, level milestone markers appear (emoji + level name from the curriculum: "Level 1: Computers Are Not Magic" through "Level 14: The Project"). The trail color transitions from green (#22C55E, beginner) through blue (#3B82F6, intermediate) to orange (#FF6B35, Claude/advanced). Mouse position warps the flow field, bending the path. Background particles slowly drift like ambient code dust. Controls: path speed, trail width, noise scale, color gradient, particle density, warp intensity. Monospace font, dark background (#09090B).

Process

From prompt to production

Each concept followed the same pipeline: prompt Clay, export the HTML, extract the creative code, adapt for the landing page hero section, and ship.

1. Prompt

Describe the visual in natural language. Clay generates a working canvas with controls.

2. Extract

Strip the Chatooly wrapper. Pull out the creative code into a standalone JS file.

3. Adapt

Convert to instance mode (p5.js) or pure canvas. Add theme awareness, reduced motion, IntersectionObserver pausing.

4. Ship

Position behind the hero content with pointer-events: none. Push to GitHub Pages. Done.
