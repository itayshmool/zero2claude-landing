# From Zero to Claude Code — Landing Page

Marketing site for [From Zero to Claude Code](https://zero2claude.dev), an interactive web app that teaches non-technical people how to use the terminal.

**Live at:** [about.zero2claude.dev](https://about.zero2claude.dev)

## Stack

Plain HTML, CSS, and JavaScript. No build step, no dependencies.

## Development

Open `index.html` in your browser. That's it.

## Deployment

Deployed automatically to GitHub Pages via GitHub Actions on push to `main`.

Custom domain configured via `CNAME` file + Namecheap DNS (CNAME record `about` -> GitHub Pages).
